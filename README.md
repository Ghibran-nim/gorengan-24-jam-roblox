# Gorengan 24 Jam — Google Antigravity Skills Pack

This package is structured for Google Gemini Antigravity workspace discovery.

## Contents

- `AGENTS.md` — always-on project instructions.
- `.agents/rules/roblox-project-standards.md` — persistent project constraints.
- `.agents/skills/*/SKILL.md` — 10 specialized Agent Skills.

## Install

1. Extract this ZIP into the root of your `gorengan-24-jam-roblox` repository.
2. Merge the included `AGENTS.md` and `.agents/` directory with existing project files. Do not overwrite valuable existing instructions without reviewing them.
3. Open the repository root as the workspace in Antigravity.
4. Open Customizations / Skills & Rules and verify the skills are discovered.
5. Start a new agent conversation if needed.
